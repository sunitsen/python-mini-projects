# python-mini-projects

A collection of Python mini-projects, fundamentals notes, and class practice exercises.

## 📁 Repository Structure

- **`mini project/`**
  - `01_calculator/`: Simple arithmetic calculator
  - `02_guessing_game/`: Number guessing game
  - `03_student_management/`: Student management application (OOP & file storage)
- **`basic/`**
  - `bootcamp_m1_c2_user_input_type_conversion_print_formating.py`: User input, data types, print formatting, error handling
  - `bootcamp_m2_c2_for_loop_list.py`: Loops (`for`, `range`), list basics, list comprehensions
  - `bootcamp_m3_c2_advanced_looping_nested_collection.py`: Nested collections, `enumerate()`, `zip()`, dictionary operations
  - `bootcamp_m4_c2_files_oop.py`: File handling, OOP pillars (Encapsulation, Inheritance, Polymorphism, Abstraction)
- **`classes/`**
  - Class exercises and practice scripts (`class1.py`, `class2.py`, `Q1.py`-`Q4.py`, etc.)
