# Python Mini Projects

Small projects built while learning Python, each applying core concepts.

| Project | Concepts practiced |
|---|---|
| `01_calculator` | classes, `__init__`, `@staticmethod`, `@classmethod`, class vs instance variables, imports |
| `02_guessing_game` | alternative constructor (`@classmethod`), validation (`@staticmethod`), `@property`, game loop |
| `03_student_management` | CRUD, multiple modules, import/export (JSON + CSV), `from_dict`/`to_dict` |

## Run
```bash
cd 01_calculator && python main.py
cd 02_guessing_game && python main.py
cd 03_student_management && python main.py
```
